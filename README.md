# 🪨 Saxum Portal

Il portale web ufficiale del brand **Saxum** (`saxum.fun`).

## 🚀 Panoramica
* **Home Page:** Design dark minimale con link ai canali social (WhatsApp, TikTok, Instagram).
* **Careers:** Modulo di candidatura per DJ, Vocalist, Immagine e Sassofonisti collegato a Web3Forms.
* **Hosting:** Statico su GitHub Pages con dominio personalizzato e HTTPS attivo.

## 🛠️ Stack Tecnologico
* HTML5, Bootstrap 5.3, Bootstrap Icons, JavaScript (Fetch API).
